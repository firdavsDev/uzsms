# django-sms-uz 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild `django-sms-uz` as a tested, pooled, backend-pluggable Django SMS app importable as `uzsms`, without renaming the database table or the PyPI distribution.

**Architecture:** A lazy settings proxy feeds a swappable backend interface; a thin client orchestrates validation, bulk logging, and one batched provider call. DRF, httpx, and Celery are optional extras behind guarded imports. Old public names survive as deprecation shims.

**Tech Stack:** Python 3.9–3.13, Django 4.2/5.x, requests, pytest + pytest-django, responses/respx, ruff. Optional: djangorestframework, httpx, celery.

**Spec:** `docs/superpowers/specs/2026-09-08-uzsms-2.0-refactor-design.md`

**Note on format:** This plan deliberately contains no code snippets, per the repository owner's global instructions. Tasks are specified by file path, interface signature, and expected behavior. Implementers write the code at execution time and must follow TDD: the test is written and observed failing before any implementation.

## Global Constraints

- Import package: `uzsms`. Django app label: **`SMS`** (pinned, never changed).
- Database table stays `SMS_smslog`. Migrations `0001`–`0003` keep their exact filenames.
- PyPI distribution name stays `django-sms-uz`. Settings key stays `SMS_SETTINGS`.
- Version becomes `2.0.0`.
- `requires-python >= 3.9`. Runtime deps: `django>=4.2`, `requests>=2.28`. Nothing else is a hard dependency.
- Importing `uzsms` with no `SMS_SETTINGS` defined must never raise.
- No public method may return a raw `requests.Response` or a bare string.
- Every outbound HTTP call passes an explicit `timeout`.
- `message_id` is generated once per `SmsMessage` and reused across retries.
- Commit messages end at the last line of the body. No attribution trailers.
- Every task ends with a passing `pytest` and `ruff check .`.
